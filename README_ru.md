## Проблема

Ты заходишь в PUG-рейд. Танк объясняет тактику — по-испански. Хилер спрашивает что-то — по-немецки. Ты говоришь по-русски (или по-английски, или по-французски). Никто никого не понимает. Начинается пулл, люди умирают, и кто-то пишет "gg noob" — единственную фразу, которую знают все.

**Это происходит постоянно** в кроссерверных и кроссрегиональных группах WoW. Языковой барьер ломает координацию, вызывает вайпы и портит удовольствие от игры.

## Решение

BabelChat переводит чат WoW **в реальном времени**. Мини-аддон перехватывает сообщения прямо из игры; приложение-компаньон переводит их через DeepL и показывает результат в стильном оверлее поверх WoW.

**Оригинальное сообщение ты видишь мгновенно. Перевод появляется через 0.5–2 секунды.**

Частые фразы ("gg", "ty", "ready?", "pull") переводятся мгновенно из встроенного разговорника — без обращения к API, без задержки. Полные предложения идут через DeepL и приходят за 1–2 секунды. Одно и то же сообщение никогда не переводится дважды (кэш).

### Когда BabelChat полезен?

- **Кроссерверные PUG-группы** — понимай тактику испанского танка, вопросы немецкого хилера
- **Международные гильдии** — следи за гильдчатом на своём языке без "english pls"
- **Игра на иностранных серверах** — зашёл на французский или корейский реалм? Чат теперь понятен
- **Рейд-лидерство** — давай команды на своём языке, игроки видят их на своём (через исходящий переводчик)
- **Шёпоты от незнакомцев** — пойми то случайное сообщение на португальском

## Возможности

- **Стриминг перевода** — оригинал появляется мгновенно, перевод подгружается через 0.5–2с
- **Автоопределение языка** — офлайн, ~1мс на сообщение (lingua-py)
- **22 языка перевода** — EN, RU, DE, FR, ES, IT, PT, PL, NL, SV, DA, FI, CS, RO, HU, BG, EL, TR, UK, JA, KO, ZH
- **Умный оверлей** — тёмная тема WoW, цвета каналов, прозрачный для кликов, перемещаемый
- **Двусторонний перевод** — переводи входящий чат И составляй исходящие сообщения на любом языке
- **Встроенный разговорник** — 45 фраз + 30 игровых аббревиатур без API
- **Словарь WoW** — 314 игровых терминов (lfm, wts, dps, tank и т.д.) на 14 языках
- **Фильтры каналов** — Группа, Рейд, Гильдия, Сказать/Крик, Шёпот, Подземелье
- **DeepL Free API** — 500 000 символов/месяц бесплатно (~10К сообщений)
- **Кэш переводов** — потокобезопасный SQLite + LRU, одно и то же не переводится дважды
- **Горячие клавиши** — переключай перевод, не выходя из игры
- **Кроссплатформенность** — поддерживаются Windows и Linux (через Proton/Wine)

## Почему перевод занимает 0.5–2 секунды?

BabelChat использует **progressive rendering** (стриминг):

1. **Оригинальное сообщение ты видишь сразу** (0мс задержки)
2. **Перевод появляется под ним** когда DeepL ответит (0.5–2с)

Задержка — это round-trip до серверов DeepL: текст отправляется, переводится нейросетью, возвращается. Это та же задержка, что у Google Translate или любого облачного переводчика.

**Мгновенно (без задержки):**
- Игровые аббревиатуры: `gg`, `ty`, `brb`, `afk`, `wp`, `lol` — из разговорника
- Частые фразы: "hello", "thanks", "ready?", "good game" — из разговорника
- Повторные сообщения — из кэша
- Сообщения на твоём языке — показываются без перевода

**0.5–2с:**
- Полные предложения на иностранных языках — нужен вызов DeepL API
- Первое вхождение любой фразы — потом кэшируется

## Как это работает

```
┌──────────────────────────────────────────────────────────┐
│  World of Warcraft                                       │
│                                                          │
│  Аддон BabelChat                                         │
│  ├── Перехватывает события CHAT_MSG_* через WoW API      │
│  ├── Кольцевой буфер (50 сообщений, сброс каждые 250мс) │
│  └── Пишет в BabelChatDB.wctbuf (Lua SavedVariable)     │
└──────────┬───────────────────────────────────────────────┘
           │  Чтение памяти (каждые 250мс)
           │  Windows: ReadProcessMemory (pymem)
           │  Linux:   process_vm_readv через Rust-сканер
           ▼
┌──────────────────────────────────────────────────────────┐
│  Приложение-компаньон (Python + Rust)                    │
│                                                          │
│  Rust-сканер ──→ Парсер ──→ Детектор языка               │
│       │                           │                      │
│       │    Разговорник (мгновенно)─┤                     │
│       │    Кэш (мгновенно) ───────┤                      │
│       │    DeepL API (0.5-2с) ────┤                      │
│       │                           ▼                      │
│       └───────────────→ Оверлей (PyQt6)                  │
└──────────────────────────────────────────────────────────┘
```

### Зачем нужно приложение-компаньон?

Lua-песочница WoW **не может делать HTTP-запросы**. Аддон перехватывает чат и показывает UI, но не может вызвать DeepL. Приложение-компаньон решает эту проблему, читая буфер аддона из памяти процесса.

BabelChat только **читает** память — никогда не пишет, не инъектирует, не автоматизирует. Warden (античит WoW) не реагирует на чтение.

> **Почему не просто читать WoWChatLog.txt?** Мы пробовали. WoW буферизирует чат-лог с буфером ~4КБ и сбрасывает непредсказуемо — задержки от 1 до 5+ минут. Наш аддон пишет в Lua-строку в памяти, а компаньон читает её каждые 250мс — задержка менее секунды.

## Обновление с ChatTranslatorHelper

Если вы использовали наш предыдущий аддон (ChatTranslatorHelper, эпоха TWW), BabelChat автоматически мигрирует настройки. Просто установите BabelChat и удалите старую папку `ChatTranslatorHelper` из `Interface/AddOns/`.

## Установка

### Windows — Быстрый старт

1. Скачай `BabelChatWindows.zip` из [Releases](https://github.com/Yumash/BabelChat/releases)
2. Распакуй и запусти `BabelChat.exe` **от имени Администратора**
3. Следуй мастеру настройки (получи [бесплатный ключ DeepL](https://www.deepl.com/pro-api), укажи путь к WoW, установи аддон)
4. Запусти WoW, зайди в группу — переводы появятся автоматически

### Linux (Proton/Wine) — Быстрый старт

1. Скачай `BabelChatLinux.zip` из [Releases](https://github.com/Yumash/BabelChat/releases)
2. Распакуй и запусти `BabelChat`
3. Следуй мастеру настройки (получи [бесплатный ключ DeepL](https://www.deepl.com/pro-api), укажи путь к WoW, установи аддон)
4. Запусти WoW, зайди в группу — переводы появятся автоматически

### Из исходников (Windows)

```bash
git clone https://github.com/Yumash/BabelChat.git
cd BabelChat
pip install -r requirements.txt
python -m app.main  # запуск от Администратора
```

### Из исходников (Linux)

```bash
git clone https://github.com/Yumash/BabelChat.git
cd BabelChat
echo 0 | sudo tee /proc/sys/kernel/yama/ptrace_scope

# Сборка Rust-сканера (обязательно для Linux)
cd babelchat_scanner
cargo build --release
cp target/release/libbabelchat_scanner.so ../app/
cd ..

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# В WoW (один раз): /run BabelChatDB.companion = {enabled = true}
QT_QPA_PLATFORM=xcb python -m app.main
```

### Аддон WoW (ручная установка)

Скопируй `addon/BabelChat/` в `World of Warcraft/_retail_/Interface/AddOns/BabelChat/`

## Приватность — что уходит с вашей машины

BabelChat переводит, отправляя текст сообщений внешнему сервису. Это значит,
что **чужие сообщения уходят третьей стороне** — включая шёпоты и гильдейский
чат, а те, кто их писал, на это не соглашались. Что стоит знать до того, как
включать каналы:

- **Что отправляется:** текст сообщений из включённых вами каналов, и больше
  ничего. Снятый канал отбрасывается до того, как уйдёт запрос.
- **Кому:** выбранному провайдеру — GigaChat (Сбер), MyMemory, DeepL или
  Microsoft. У каждого своя политика обработки данных.
- **Что хранится локально:** переводы кэшируются на семь суток вместе с
  исходным текстом, чтобы не платить за одну строку дважды. *Настройки →
  Очистить кэш переводов* удаляет всё.
- **Что не хранится:** о перехваченном чате на диск не пишется ничего, пока вы
  сами не включите *Записывать перехваченный чат в файл* для разбора проблемы.
  В этом файле сообщения лежат целиком — выключайте, когда закончите.
- **Шёпоты** — самый чувствительный канал, и он включён по умолчанию. Если
  машина общая или в гильдии этого не ждут, снимите галку.

Встроенный словарь аддона не отправляет никуда ничего: он работает целиком
внутри WoW, поэтому установка без компаньона не создаёт исходящего трафика
вовсе.

## Ограничения

- **Требуется расширенный доступ к памяти** — права Администратора на Windows; `ptrace_scope=0` на Linux
- **Композитор Linux** — требуется поддержка протокола layer-shell (в GNOME она отсутствует).
- **Лимит DeepL Free** — 500К символов/месяц (~10К сообщений). Есть платные планы
- **Исходящие сообщения** — копируй → вставляй в чат WoW (осознанно, для соответствия ToS)

## Технологии

| Компонент          | Технология                                                                  |
| ------------------ | --------------------------------------------------------------------------- |
| Приложение         | Python 3.12, PyQt6                                                          |
| Memory Reader      | Windows: pymem (ReadProcessMemory) / Linux: Rust (`process_vm_readv`)       |
| Rust-сканер        | Rayon (параллельное сканирование), потоки SCHED\_IDLE, кэш адреса           |
| Определение языка  | lingua-py (офлайн)                                                          |
| Перевод            | DeepL API                                                                   |
| Кэш                | SQLite + LRU                                                                |
| Сборка             | PyInstaller → одиночный бинарник (Windows .exe / Linux ELF)                 |
| Аддон              | Lua 5.1, WoW API                                                            |
| Тесты              | 133 теста (pytest)                                                          |
