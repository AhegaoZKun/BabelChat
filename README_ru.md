## Проблема

Ты заходишь в PUG-рейд. Танк объясняет тактику — по-испански. Хилер спрашивает что-то — по-немецки. Ты говоришь по-русски (или по-английски, или по-французски). Никто никого не понимает. Начинается пулл, люди умирают, и кто-то пишет "gg noob" — единственную фразу, которую знают все.

**Это происходит постоянно** в кроссерверных и кроссрегиональных группах WoW. Языковой барьер ломает координацию, вызывает вайпы и портит удовольствие от игры.

## Решение

BabelChat переводит чат WoW **в реальном времени**. Мини-аддон перехватывает сообщения прямо из игры; приложение-компаньон отправляет их сервису перевода и показывает результат в стильном оверлее поверх WoW.

**Оригинальное сообщение ты видишь мгновенно. Перевод появляется через 0.5–2 секунды.**

Частые фразы ("gg", "ty", "ready?", "pull") переводятся мгновенно из встроенного разговорника — без обращения к API, без задержки. Полные предложения уходят провайдеру и приходят за 1–2 секунды. Одно и то же сообщение никогда не переводится дважды (кэш).

### Когда BabelChat полезен?

- **Кроссерверные PUG-группы** — понимай тактику испанского танка, вопросы немецкого хилера
- **Международные гильдии** — следи за гильдчатом на своём языке без "english pls"
- **Игра на иностранных серверах** — зашёл на французский или корейский реалм? Чат теперь понятен
- **Рейд-лидерство** — давай команды на своём языке, игроки видят их на своём (через исходящий переводчик)
- **Шёпоты от незнакомцев** — пойми то случайное сообщение на португальском

## Возможности

- **Стриминг перевода** — оригинал появляется мгновенно, перевод подгружается через 0.5–2с
- **Автоопределение языка** — офлайн, ~1мс на сообщение (lingua-py)
- **22 языка перевода** — EN, RU, DE, FR, ES, IT, PT, PL, NL, SV, DA, FI, CS, RO, HU, BG, EL, TR, UK, JA, KO, ZH
- **Умный оверлей** — тёмная тема WoW, цвета каналов, прозрачный для кликов, перемещаемый
- **Двусторонний перевод** — переводи входящий чат И составляй исходящие сообщения на любом языке
- **Встроенный разговорник** — 53 фразы + 75 игровых аббревиатур без API
- **Словарь WoW** — 436 игровых терминов (lfm, wts, dps, tank и т.д.) на 14 языках
- **Фильтры каналов** — Группа, Рейд, Гильдия, Сказать, Крик, Шёпот, Подземелье, Торговля, Общий, Услуги, Поиск группы, Свои каналы, Эмоции
- **Четыре провайдера перевода** — GigaChat (по умолчанию), MyMemory, DeepL, Microsoft. Если основной не ответил или упёрся в лимит, сообщение берёт следующий настроенный
- **Кэш переводов** — потокобезопасный SQLite + LRU, одно и то же не переводится дважды
- **Горячие клавиши** — переключай перевод, не выходя из игры
- **Кроссплатформенность** — поддерживаются Windows и Linux (через Proton/Wine)

## Провайдеры перевода

В приложении их четыре. Цепочка пробуется в этом порядке, и провайдер, который
не ответил или упёрся в лимит, передаёт сообщение следующему:

| Провайдер | Сколько стоит | Что нужно |
| --- | --- | --- |
| **GigaChat** (Сбер) — по умолчанию | Бесплатно для физлиц: 1 млн токенов в год, примерно 50 000–70 000 сообщений | Сбер ID. Без карты. Работает из России без VPN — [как получить ключ](https://github.com/Yumash/BabelChat/blob/main/docs/user/gigachat_ru.md) |
| **MyMemory** | Бесплатно | Ничего вообще. Работает с первого запуска, до любой настройки, поэтому перевод не бывает мёртвым сразу. Качество ниже остальных, поэтому стоит в цепочке под ними |
| **DeepL** | Бесплатный тариф: 500 тыс. символов в месяц (~10К сообщений) | При регистрации просят карту для подтверждения личности, деньги не списывают |
| **Microsoft Translator** | Бесплатный тариф: 2 млн символов в месяц, карта не нужна | Аккаунт Azure |

GigaChat идёт первым потому, что из четырёх он единственный, куда игрок из
России может зарегистрироваться без зарубежной карты и VPN. Любой из них можно
сделать основным в *Настройках → Основные*, и мастер настройки спрашивает об
этом при первом запуске.

## Почему перевод занимает 0.5–2 секунды?

BabelChat использует **progressive rendering** (стриминг):

1. **Оригинальное сообщение ты видишь сразу** (0мс задержки)
2. **Перевод дописывается в ту же строку** после стрелки, когда провайдер ответит (0.5–2с)

Задержка — это round-trip до серверов провайдера: текст отправляется, переводится нейросетью, возвращается. Это та же задержка, что у Google Translate или любого облачного переводчика.

**Мгновенно (без задержки):**
- Игровые аббревиатуры: `gg`, `ty`, `brb`, `afk`, `wp`, `lol` — из разговорника
- Частые фразы: "hello", "thanks", "ready?", "good game" — из разговорника
- Повторные сообщения — из кэша
- Сообщения на твоём языке — показываются без перевода

**0.5–2с:**
- Полные предложения на иностранных языках — нужен вызов API провайдера
- Первое вхождение любой фразы — потом кэшируется

## Как это работает

```
┌──────────────────────────────────────────────────────────┐
│  World of Warcraft                                       │
│                                                          │
│  Аддон BabelChat                                         │
│  ├── Перехватывает события CHAT_MSG_* через WoW API      │
│  ├── Кольцевой буфер (50 сообщений, сброс каждые 250мс) │
│  └── Пишет в BabelChatDB.wctbuf (Lua SavedVariable)     │
└──────────┬───────────────────────────────────────────────┘
           │  Чтение памяти (каждые 250мс) по указателю, который
           │  аддон для этого и кладёт — без поиска, ~0,1% ядра
           │  Windows: ReadProcessMemory / Linux: process_vm_readv
           ▼
┌──────────────────────────────────────────────────────────┐
│  Приложение-компаньон (Python + Rust)                    │
│                                                          │
│  Rust-сканер ──→ Парсер ──→ Детектор языка               │
│       │                           │                      │
│       │    Разговорник (мгновенно)─┤                     │
│       │    Кэш (мгновенно) ───────┤                      │
│       │    API провайдера (0.5-2с)┤                      │
│       │                           ▼                      │
│       └──────────→ Оверлей (PyQt6 / GTK4)                │
└──────────────────────────────────────────────────────────┘
```

### Зачем нужно приложение-компаньон?

Lua-песочница WoW **не может делать HTTP-запросы**. Аддон перехватывает чат и показывает UI, но не может обратиться к API перевода. Приложение-компаньон решает эту проблему, читая буфер аддона из памяти процесса.

BabelChat только **читает** память — никогда не пишет, не инъектирует, не автоматизирует. Warden (античит WoW) не реагирует на чтение.

> **Почему не просто читать WoWChatLog.txt?** Мы пробовали. WoW буферизирует чат-лог с буфером ~4КБ и сбрасывает непредсказуемо — задержки от 1 до 5+ минут. Наш аддон пишет в Lua-строку в памяти, а компаньон читает её каждые 250мс — задержка менее секунды.

## Обновление с ChatTranslatorHelper

Если вы использовали наш предыдущий аддон (ChatTranslatorHelper, эпоха TWW), BabelChat автоматически мигрирует настройки. Просто установите BabelChat и удалите старую папку `ChatTranslatorHelper` из `Interface/AddOns/`.

## Установка

### Windows — Быстрый старт

1. Скачай `BabelChat.zip` из [Releases](https://github.com/Yumash/BabelChat/releases)
2. Распакуй и запусти `BabelChat.exe` — права администратора **не нужны**
3. Следуй мастеру настройки (выбери переводчик, укажи путь к WoW, установи аддон). GigaChat бесплатен для физлиц и не просит карту; этот шаг можно и пропустить, оставив только внутриигровой словарь.
4. Запусти WoW, зайди в группу — переводы появятся автоматически

### Linux (Proton/Wine) — Быстрый старт

1. Скачай `.AppImage`, `.deb` или `.rpm` из [Releases](https://github.com/Yumash/BabelChat/releases) — AppImage не требует установки, пакеты ставятся как `babelchat`
2. Запусти (`chmod +x BabelChat-*.AppImage && ./BabelChat-*.AppImage` или `babelchat` после установки пакета)
3. Следуй мастеру настройки (выбери переводчик, укажи путь к WoW, установи аддон). GigaChat бесплатен для физлиц и не просит карту; этот шаг можно и пропустить, оставив только внутриигровой словарь.
4. Запусти WoW, зайди в группу — переводы появятся автоматически

Отдельно аддон лежит в том же релизе — `BabelChat-Addon.zip`; распакуй его в
`Interface/AddOns/`, если нужен только внутриигровой словарь.

### Из исходников (Windows)

```bash
git clone https://github.com/Yumash/BabelChat.git
cd BabelChat
pip install -r requirements.txt
python -m app.main
```

### Из исходников (Linux)

```bash
git clone https://github.com/Yumash/BabelChat.git
cd BabelChat
echo 0 | sudo tee /proc/sys/kernel/yama/ptrace_scope

# Сборка Rust-сканера (обязательно для Linux)
cargo build --release --manifest-path babelchat_scanner_linux/Cargo.toml
cp babelchat_scanner_linux/target/release/libbabelchat_scanner.so app/

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app.main_gtk
```

Аддон не пишет буфер в память, пока компаньон не включён: в WoW `/babel config`
→ **Приложение-компаньон** → поставь галку. Без неё внутриигровой словарь
работает, а оверлей остаётся пустым.

### Аддон WoW (ручная установка)

Скопируй `addon/BabelChat/` в `World of Warcraft/_retail_/Interface/AddOns/BabelChat/`

чтобы одно сообщение не переводилось дважды разными словами.

### Как добавить новый термин

Отредактируй файл `addon/BabelChat/Data/*.lua`:

```lua
["newterm"] = {
    enUS = "English translation",
    esES = "Traducción española",
    ruRU = "Русский перевод",
    deDE = "Deutsche Übersetzung",
    frFR = "Traduction française",
    -- ... (14 языков)
},
```

## Приватность — что уходит с вашей машины

BabelChat переводит, отправляя текст сообщений внешнему сервису. Это значит,
что **чужие сообщения уходят третьей стороне** — включая шёпоты и гильдейский
чат, а те, кто их писал, на это не соглашались. Что стоит знать до того, как
включать каналы:

- **Что отправляется:** текст сообщений из включённых вами каналов, и больше
  ничего. Снятый канал отбрасывается до того, как уйдёт запрос.
- **Кому:** выбранному провайдеру — GigaChat (Сбер), MyMemory, DeepL или
  Microsoft. У каждого своя политика обработки данных.
- **Что хранится локально:** переводы кэшируются на семь суток вместе с
  исходным текстом, чтобы не платить за одну строку дважды. *Настройки →
  Очистить кэш переводов* удаляет всё.
- **Что не хранится:** о перехваченном чате на диск не пишется ничего, пока вы
  сами не включите *Записывать перехваченный чат в файл* для разбора проблемы.
  В этом файле сообщения лежат целиком — выключайте, когда закончите.
- **Шёпоты** — самый чувствительный канал, и он включён по умолчанию. Если
  машина общая или в гильдии этого не ждут, снимите галку.

Встроенный словарь аддона не отправляет никуда ничего: он работает целиком
внутри WoW, поэтому установка без компаньона не создаёт исходящего трафика
вовсе.

## Ограничения

- **Читает память процесса** — без повышения прав на Windows; `ptrace_scope=0` на Linux
- **Композитор Linux** — оверлей поднимается над полноэкранной игрой только там, где есть layer-shell. На X11 работает запасной вариант — обычное окно поверх остальных; на GNOME Wayland нет ни того, ни другого, и приложение открывается обычным окном, о чём предупреждает при первом запуске
- **Лимиты бесплатных тарифов** — они есть у каждого провайдера (см. таблицу выше). Когда один заканчивается, цепочка переходит к следующему
- **Исходящие сообщения** — копируй → вставляй в чат WoW (осознанно, для соответствия ToS)
