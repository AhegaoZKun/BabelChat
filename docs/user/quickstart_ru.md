# Быстрый старт

## Требования

- Windows 10/11
- World of Warcraft (Retail — The War Within / Midnight)
- Ничего больше. Перевод работает сразу: встроенный словарь игровых терминов не требует
  ничего, а MyMemory переводит целыми фразами без аккаунта и ключа.

Ключ нужен, только если хочется перевода получше. Варианты в порядке доступности из России:

| Провайдер | Что нужно | Лимит |
| --- | --- | --- |
| **GigaChat** (по умолчанию) | Sber ID, карта не нужна, VPN не нужен | 1 млн токенов в год |
| MyMemory | ничего | 5 000 слов в день, 50 000 с указанным e-mail |
| DeepL | карта для подтверждения личности, деньги не списывают | 500 тыс. символов в месяц |
| Microsoft Translator | аккаунт Azure | 2 млн символов в месяц |

## Шаг 1: Скачивание

Скачай `BabelChat.zip` из [GitHub Releases](https://github.com/Yumash/BabelChat/releases).

Распакуй куда угодно: на рабочий стол, в загрузки, разницы нет.

## Шаг 2: Запуск

Двойной клик по `BabelChat.exe`.

> Права администратора **не нужны**. `ReadProcessMemory` для процесса того же
> пользователя работает без них, а постоянно повышенные права превращают
> обычную ошибку в подмену библиотеки в захват системы. Если старая инструкция
> говорила запускать от администратора — она устарела, так делать не надо.

## Шаг 3: Мастер настройки

При первом запуске мастер проведёт тебя через 5 шагов:

### 3.1 Приветствие
Выбери язык интерфейса (Английский, Русский или Испанский).

### 3.2 Провайдер перевода

Этот шаг можно пропустить целиком: без единого ключа перевод уже работает через
MyMemory, а внутриигровой словарь работает всегда.

Хочется перевода получше? Заполни того провайдера, который у тебя есть.
Рекомендуемый для России — **GigaChat**:

1. Зайди в [Studio Sber](https://developers.sber.ru/studio/workspaces) через Sber ID
2. Создай проект GigaChat API и получи **ключ авторизации** (это base64 от
   `client_id:client_secret`)
3. Вставь его в поле GigaChat и нажми «Проверить»

Поле «Корневой сертификат» заполнять не нужно: оно пригодится, только если
соединение упрётся в проверку TLS.

### 3.3 Путь к WoW
BabelChat попробует найти WoW сам. Не найдёт — нажми "Обзор" и выбери папку `World of Warcraft`.

### 3.4 Языки
- **Твой язык** — язык, на котором ты говоришь (сообщения на этом языке не переводятся)
- **Целевой язык** — на какой язык переводить иностранные сообщения (по умолчанию
  совпадает с языком интерфейса)

### 3.5 Установка аддона
Нажми "Установить аддон", и BabelChat скопирует его в папку WoW. Или скопируй `addon/BabelChat/` вручную:
```
World of Warcraft/_retail_/Interface/AddOns/BabelChat/
```

## Шаг 4: Запуск WoW

1. Запусти World of Warcraft
2. На экране выбора персонажа нажми **Аддоны** и убедись что "BabelChat" включён
3. Зайди в игру
4. В чате появится: *"Добро пожаловать в BabelChat!"*

## Шаг 5: Играй

Зайди в группу и общайся. BabelChat будет:
- Показывать **оригинальное сообщение мгновенно** в оверлее
- Показывать **перевод через 0.5-2 секунды** под ним
- Частые фразы (gg, ty, brb) переводятся **мгновенно** без задержки

## Что ты увидишь

Оверлей появляется поверх WoW с тёмным полупрозрачным фоном:

- **Цвета каналов** совпадают с WoW (синий — Группа, оранжевый — Рейд, зелёный — Гильдия)
- **Оригинал** серым цветом
- **Перевод** золотым, со стрелкой: `→ переведённый текст`
- **Вкладки-фильтры** сверху для показа только нужных каналов

## Советы

- **Переключи перевод** нажатием `Ctrl+Shift+T` (настраивается)
- **Ответь на другом языке**: кликни в поле ответа, напиши сообщение, Enter → перевод скопирован в буфер → вставь в WoW через `Ctrl+V`
- **Сверни оверлей** кнопкой в заголовке
- **Двигай/изменяй размер** перетаскиванием заголовка или нижнего правого угла
- Оверлей **прозрачен для кликов** — клики проходят сквозь него в WoW
