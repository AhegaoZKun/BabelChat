# Настройка

## Диалог настроек

Открывается через кнопку в оверлее или системный трей → Настройки.

### Вкладка "Основные"

| Параметр | Описание |
|----------|----------|
| Сервисы перевода | По строке на провайдера: GigaChat, MyMemory, DeepL, Microsoft Translator. Заполняйте тот, который у вас есть — каждый проверяется на месте, а поле «Основной» выбирает, кого пробовать первым |
| Путь к WoW | Автоопределение или ручной выбор. Кнопка "Установить аддон" |
| Язык интерфейса | RU, EN, ES |
| Ваш язык | Сообщения на этом языке не переводятся |
| Целевой язык | На какой язык переводить |
| Каналы | Группа, Рейд, Гильдия, Сказать, Крик, Шёпот, Подземелье, Торговля, Общий, Услуги, Поиск группы, свои каналы, эмоции |
| Не переводить свои | Ваши сообщения не переводятся (имя определяется автоматически) |

### Вкладка "Оверлей"

| Параметр | Описание |
|----------|----------|
| Прозрачность | 20-100% |
| Размер шрифта | 8-20pt |
| Перевод включён по умолчанию | Запускать с включённым переводом |
| Отладочная консоль | Показать окно отладки |

### Вкладка "Горячие клавиши"

| По умолчанию | Действие |
|-------------|----------|
| `Ctrl+Shift+T` | Вкл/выкл перевод |
| `Ctrl+Shift+C` | Перевести буфер обмена |

Кликни на поле и нажми нужную комбинацию для настройки.

## Настройки аддона в WoW

В WoW: ESC → Интерфейс → Аддоны → BabelChat

| Раздел | Параметры |
|--------|-----------|
| Общие | Вкл/выкл словарь, цвет перевода |
| Категории | 15 переключателей для категорий терминов |
| Каналы | Какие каналы чата переводить |
| Язык | На каком языке пишется подсказка. При первом запуске берётся у клиента WoW; доступно 14 |
| Компаньон | Вкл/выкл буфер для приложения-компаньона |
| Режим | По умолчанию аддон молчит, пока работает приложение-компаньон, чтобы одно и то же сообщение не переводилось дважды разными словами. Галочка «Показывать подсказку, даже когда работает приложение» это отменяет |

## Команды аддона

| Команда | Описание |
|---------|----------|
| `/babel` | Показать справку |
| `/babel config` | Открыть настройки WoW |
| `/babel on` / `off` | Вкл/выкл словарный перевод |
| `/babel test` | Тест с примером |
| `/babel companion` | Статус буфера компаньона |
| `/babel poll on` / `off` | Вкл/выкл fallback опрос ChatFrame |
| `/babel log on` / `off` | Вкл/выкл логирование чата |

## config.json

Все настройки хранятся в `config.json` (создаётся автоматически). Править руками
не обязательно, но можно:

```json
{
  "providers": {
    "gigachat": { "authorization_key": "base64 от client_id:client_secret" },
    "mymemory": { "email": "" }
  },
  "translator_priority": "gigachat",
  "wow_path": "D:/World of Warcraft",
  "ui_language": "RU",
  "own_language": "RU",
  "target_language": "RU",
  "overlay_opacity": 180,
  "overlay_font_size": 10,
  "hotkey_toggle_translate": "Ctrl+Shift+T",
  "channels_party": true,
  "channels_raid": true,
  "channels_guild": true,
  "channels_say": true,
  "channels_yell": false,
  "channels_whisper": true,
  "channels_instance": true,
  "channels_trade": false,
  "channels_general": false,
  "channels_services": false,
  "channels_lfg": false,
  "channels_custom": false,
  "channels_emote": false,
  "skip_own_messages": true,
  "show_debug_console": false,
  "debug_capture_trace": false
}
```

Ключи лежат в `providers`, по идентификатору провайдера. В старых конфигах было
по одному плоскому полю на провайдера (`deepl_api_key`, `microsoft_api_key`,
`microsoft_region`) — они переносятся при загрузке, так что существующий файл
продолжает работать.

Резервная копия `config.json.bak` создаётся перед каждым сохранением. Учтите:
ключ провайдера лежит в обоих файлах открытым текстом, поэтому не прикладывайте
их к issue и не выкладывайте в чат.
